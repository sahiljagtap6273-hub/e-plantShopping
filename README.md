# Paradise Nursery Shopping Application

A dynamic shopping cart application for an online plant shop called Paradise Nursery. Users can browse a variety of houseplants, view details such as images, names, descriptions, and prices, add plants to a shopping cart, and manage cart items.

## Features
- Landing page with a "Get Started" button
- Navigation bar with links to Home, Plants, and Cart
- Product listing page with plants grouped into categories
- Add to Cart functionality with disabled button after adding
- Shopping cart page with quantity adjustment, delete, and total cost
- Redux state management for cart items

## Tech Stack
- React
- Redux Toolkit
- React Redux
- Vite
- CSS
